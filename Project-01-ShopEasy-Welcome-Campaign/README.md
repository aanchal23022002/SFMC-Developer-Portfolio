# Project 01: ShopEasy Welcome Campaign

## Project Overview

This project demonstrates the conceptual design
of a customer welcome email campaign using
Salesforce Marketing Cloud Engagement.

## Business Scenario

ShopEasy is an e-commerce company.

The company wants to send welcome emails
to newly registered customers who have
provided marketing consent.

## Business Requirements

1. Store customer information.
2. Identify newly registered customers.
3. Check marketing consent.
4. Send welcome emails to eligible customers.
5. Track email campaign performance.

## SFMC Components

- Data Extensions
- Contact Builder
- Content Builder
- Journey Builder

## Project Status

Conceptual design completed.

No live SFMC implementation has been performed yet.

## Learning Objectives

- Understand SFMC fundamentals.
- Understand customer segmentation.
- Understand marketing consent.
- Understand welcome journey design.
